# Python for ML — NumPy Fundamentals

This repository contains my hands-on implementation of NumPy fundamentals as part of the Python for ML learning module.

## Topics Covered

- NumPy installation and environment setup
- 1D, 2D, and 3D arrays
- Array shapes and dimensions
- Broadcasting
- Vectorized operations
- Matrix multiplication
- Statistical operations
- Working with the Iris dataset
- Basic data analysis using NumPy

## Files

### `numpy_fundamentals.py`
Contains the NumPy implementations and practical exercises.

### `iris_dataset.csv`
Dataset used for NumPy-based analysis and statistical operations.

### `.gitignore`
Contains files and folders that should not be committed to Git.

## Technologies

- Python
- NumPy
- Pandas
- Scikit-learn

## Environment

The project is developed using a Python virtual environment (`.venv`).
